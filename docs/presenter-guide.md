# Presenter guide

Claude AI: Beyond Conversational AI · CloudSwyft Claude AI Training Series · 30 minutes on Microsoft Teams

## Before the session (15 minutes ahead)

1. Open the presentation in **Chrome or Edge**: run `npm run dev` and go to http://localhost:5173, or use the hosted link.
2. Click **Start in fullscreen**. This also allows the browser to play sound.
3. Press **N** to open the **presenter notes window**. Move it to your second screen, or beside Teams. **Don't share this window.** If the browser blocks the popup, allow popups for the site and press N again.
4. In Teams: **Share → Window →** choose the presentation window, and turn on **Include sound**.
5. Paste the 7 Educaplay links into a note so you can post them in chat quickly. They're also on each game slide.
6. Press **T** and click **Reset**, then **Start**, when you begin, so the timer matches the session.

## During the session

| Key | Action |
|---|---|
| → / Space | Next step or scene |
| ← | Back |
| P / R | Pause or replay narration (or play the documentary) |
| M | Mute |
| C | Documentary captions on/off |
| S | Section menu: jump anywhere, including the Reference slides |
| T | Timer: session clock and whether you're ahead or behind plan |
| N | Presenter notes window |
| B | Background music on/off (it automatically gets quieter while the voice speaks) |
| F | Fullscreen |

The notes window shows the script for the current scene, cues in yellow (what to click),
what comes next, and Back / Play / Next buttons that control the main window.

## Games (about 60 seconds each)

On each game slide:

1. Click **Copy link** and paste it in the Teams chat (the QR code is the backup for phones).
2. Click **Launch game** if you want to play along on screen.
3. Wait about 10 seconds for people to join, then let the game run.
4. Click **Continue** (or press →) when time is up.

**If Educaplay or the internet fails:** skip the game and ask one quick question
out loud from that part instead. The presentation keeps working offline. Only the games need internet.

## Documentaries (40 seconds each)

Each one is a motion-graphics video (about 35 seconds) with the voiceover built in. They wait
on a play button. Press **P** or click play. Captions are on by default (C toggles them).
The background music keeps playing softly under the video. When it ends, the last frame
(the title card) stays up; press → to continue.

## If something goes wrong

| Problem | Fix |
|---|---|
| No sound in Teams | Re-share with **Include sound** on. Check the dock isn't muted (M). |
| Dock says "Voice pending" | That narration file isn't recorded yet. Read the script from the notes window. |
| Dock says "Click play to allow sound" | Click the play button in the dock once. |
| Wrong slide after a reload | The address keeps the scene (e.g. `#3.2`), so reloading returns there. Use S to jump. |
| Running late | Check T. Shorten 3.1, 3.2, 5.1 or 6.2 (fewer clicks), or skip 4.x. Don't drop a game without agreeing it first. |
| Questions about competitors, pricing or market share | Open the Reference slides from the section menu (S): R1–R5. |
